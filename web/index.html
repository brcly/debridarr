R

Retention

How long a downloaded title stays cached before it's deleted.

Delete anyway after this many extra days if the ratio target is never reached. 0 = never force it.

0 = unlimited. Over the cap, the soonest-to-expire titles that aren't Kept are evicted first.

Q

Preferences

Language and quality filtering for search results. Pick as many as you like — anything unchecked here is never shown.

None checked = any resolution. A release with no readable resolution always shows.

None checked = any codec. A release with no readable codec always shows. x265/HEVC encodes to a smaller file at the same quality than x264.

None checked = any language. An untagged or multi-language (MULTI/DUAL) release always shows.
